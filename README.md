# Loan Default Prediction

A machine learning project that predicts the probability of loan default using LendingClub data (2007–2018). Includes a trained LightGBM model and an interactive Streamlit dashboard with SHAP explainability.

## Project Structure

```
├── lending_club_models.ipynb   # Data preprocessing, feature engineering, model training & evaluation
├── app.py                      # Streamlit web app for real-time default risk prediction
├── model_artifacts.joblib      # Trained model + encoders (generated after running the notebook)
└── extracted_dataset/          # Raw data (not tracked — see download instructions below)
```

## Features

- **LightGBM classifier** with isotonic calibration for well-calibrated probabilities
- **SHAP waterfall plots** explaining individual predictions
- **Interactive dashboard** — adjust applicant attributes and get instant risk scores
- Custom engineered features: DTI × utilization interaction, income-to-loan ratio, payment-to-income ratio, and more

## Dataset

The raw data is not included in this repository due to file size. Download from Kaggle:

- [LendingClub Accepted Loans 2007–2018](https://www.kaggle.com/datasets/wordsforthewise/lending-club)

Place the downloaded files in `extracted_dataset/` before running the notebook.

## Setup

```bash
# 1. Clone the repo
git clone https://github.com/am4nsingh/Loan-Default-Prediction.git
cd Loan-Default-Prediction

# 2. Install dependencies
pip install streamlit lightgbm scikit-learn shap pandas numpy joblib matplotlib

# 3. Train the model (run the notebook end-to-end first)
jupyter notebook lending_club_models.ipynb

# 4. Launch the dashboard
streamlit run app.py
```

> The app expects `model_artifacts.joblib` in the same directory as `app.py`. This file is generated by the final cell of the notebook.
